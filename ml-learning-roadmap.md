# Machine Learning Roadmap — Free, Project-Based, Certificate-Backed

**Total duration:** ~70 days (10 weeks) at roughly 1–1.5 hrs/day, 5 days/week.
Adjust pace up or down — the day counts are guardrails, not deadlines carved in stone.

---

## Phase 1: Foundations — Kaggle Learn (Days 1–18)

Fills the numpy/pandas/seaborn gap. Each course ends in a certificate + a real Kaggle notebook submission.

| Days | Course | Link | What you get |
|---|---|---|---|
| 1–3 | Pandas | https://www.kaggle.com/learn/pandas | Data wrangling — the #1 daily-use skill |
| 4–6 | Intro to Machine Learning | https://www.kaggle.com/learn/intro-to-machine-learning | Your first trained model, decision trees |
| 7–9 | Data Visualization | https://www.kaggle.com/learn/data-visualization | Matplotlib + **Seaborn** |
| 10–13 | Intermediate Machine Learning | https://www.kaggle.com/learn/intermediate-machine-learning | Missing data, categorical data, pipelines, XGBoost |
| 14–18 | Feature Engineering | https://www.kaggle.com/learn/feature-engineering | Turning raw data into model-ready features |

**Checkpoint (Day 18):** You should have 5 Kaggle certificates and at least one submission on the [Titanic](https://www.kaggle.com/c/titanic) or [House Prices](https://www.kaggle.com/c/house-prices-advanced-regression-techniques) leaderboard.

## Phase 2: freeCodeCamp — Machine Learning with Python (Days 19–70)

**Course hub:** https://www.freecodecamp.org/learn/machine-learning-with-python/

### 2a. Core concepts (Days 19–24)
- TensorFlow basics (Tech With Tim video course, built into the freeCodeCamp curriculum)
- How Neural Networks Work (Brandon Rohrer module)

### 2b. The 5 certification projects

| Days | Project | Skill focus |
|---|---|---|
| 25–30 | Rock Paper Scissors (build an AI opponent) | Game logic + basic ML strategy |
| 31–40 | Cat and Dog Image Classifier | CNNs, image data, TensorFlow |
| 41–48 | Book Recommendation Engine (KNN) | Recommendation systems, nearest neighbors |
| 49–55 | Linear Regression Health Costs Calculator | Regression, numeric prediction |
| 56–65 | Neural Network SMS Text Classifier | NLP, text classification |

### 2c. Wrap-up (Days 66–70)
- Polish and push all 5 projects to a GitHub repo (one folder per project, short README each)
- Submit final projects on freeCodeCamp → claim your **Machine Learning with Python Certification**

## Rules to stay on track

1. **Code every line yourself** — no copy-paste-and-move-on, even in the video-heavy freeCodeCamp sections.
2. **Don't skip Phase 1** — the freeCodeCamp course assumes pandas/numpy comfort it doesn't fully teach.
3. **If a day's task isn't done, don't extend it — carry only the unfinished part forward.** Compounding delays kill more learners than difficulty does.
4. **Push to GitHub as you go**, not at the end — a project isn't "done" until it has a repo and a README.
